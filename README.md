# 🚀 AI-Powered Cryptocurrency Analytics Platform

An institutional-grade, full-stack cryptocurrency analysis dashboard built with Python and Streamlit. This application tracks real-time global market data, computes advanced technical indicators, manages multi-asset portfolios, and utilizes Machine Learning (Linear Regression) to forecast price trends.

![Dashboard Preview](assets/dashboard.png) *(Note: Add your screenshot here)*

## 🌟 Features
* **Live Market Intelligence:** Real-time fetching of top cryptocurrencies via CoinGecko API.
* **Technical Analysis Suite:** Automated calculations and dynamic charting for 7-Day Moving Averages, RSI (14), and MACD signals.
* **Portfolio Manager:** Interactive multi-asset tracker featuring automated weight allocation, valuation, and downloadable CSV audit reports.
* **AI Price Predictor:** Scikit-Learn integration forecasting next-session price targets and algorithmic Buy/Hold/Sell signals.
* **Modern UI/UX:** Segmented sidebar navigation, metric cards, and responsive Plotly visualizations.

## 🛠️ Technology Stack
* **Language:** Python 3.10+
* **Frontend/Framework:** Streamlit
* **Data Manipulation:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn
* **Data Visualization:** Plotly Express
* **APIs:** Requests, CoinGecko API
